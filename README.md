# Time Bubble Sand

Мини-песочница в стиле falling-sand (клеточный автомат, как Sandspiel / Noita), с одной ключевой механикой: **физика работает только внутри небольшого круга («пузырь времени») вокруг игрока**. Всё за пределами пузыря полностью заморожено — клетки не обновляются. Это игровая механика, а не оптимизация.

## Как запустить локально

Проект — статические файлы без сборки и зависимостей.

1. Клонируйте репозиторий.
2. Запустите простой HTTP-сервер в корне проекта (модули ES требуют HTTP, `file://` обычно не подходит):

```bash
python3 -m http.server 8080
```

3. Откройте в браузере: `http://localhost:8080`

Работает в десктопных и мобильных браузерах.

## Управление

| Действие | Клавиши / жесты |
|----------|------------------|
| Движение игрока | **WASD** или **стрелки**; на мобильных — кнопки на экране |
| Рисование материала | **ЛКМ** / касание по полю |
| Выбор материала | Кнопки палитры или клавиши **1–6** |
| Радиус пузыря | **[** уменьшить, **]** увеличить; на мобильных — ползунок |

Материалы: пусто, камень, песок, вода, огонь (поджигает дерево и гаснет), дерево.

Рисовать можно **в любом месте**, в том числе в замороженной зоне. Симуляция же обновляет только клетки внутри пузыря; жидкости и песок **не могут перетечь** за границу пузыря — внешний мир для них как стена.

## GitHub Pages

1. В настройках репозитория на GitHub: **Settings → Pages**.
2. **Source**: Deploy from a branch.
3. **Branch**: `main`, папка **`/ (root)`**.
4. Сохраните. Через минуту сайт будет доступен по адресу вида `https://<user>.github.io/time-bubble-sand/`.

Дополнительная сборка не нужна — отдаётся `index.html` и папка `js/`.

## Структура

- `index.html` — разметка, canvas 320×180
- `style.css` — масштабирование с `image-rendering: pixelated`
- `js/` — симуляция, отрисовка, ввод

Стартовая сцена: зависшая «замороженная» куча песа, водопад, дерево с огнём и песок справа — подвигайте пузырь, чтобы «оживить» участки мира.
